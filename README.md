# Bengaluru Rental Market - EDA & KPI Analysis
### Data Analyst Project by Hajira Shaikh | Bengaluru

## Project Overview
Analyzed 1200+ Bengaluru rental records to identify trends, check data quality, and calculate business KPIs using Python.

## Skills Used
- Python: Pandas, NumPy, Matplotlib
- Data Cleaning: Handled 12.5% missing values, duplicates
- Data Quality Checks: Profiling, missing value analysis
- EDA & KPIs: Avg Rent, Rent per sqft, BHK Demand
- Tools: Jupyter Notebook, GitHub

## Dataset
1200 records: Area, BHK, Size_sqft, Rent_INR, Age_years, Furnishing

## Key Findings
1. Data Quality: Found 12.5% missing rent values - fixed using median by BHK
2. Premium Areas: Koramangala (Rs 25,866 avg), Jayanagar, Indiranagar highest rent
3. Demand: 2BHK = 49.3% of market (highest demand), 1BHK = 30.5%, 3BHK = 20.2%
4. Trend: Location matters more than size for rent in Bengaluru
5. KPI: Average Rent per sqft = Rs 22.5

## Business Recommendation
Focus on 2BHK in HSR/Whitefield - high demand, moderate rent, best ROI.
